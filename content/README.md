## 校验与导入

```sh
npm test
npm run typecheck
# 先只读核对正式库的题量、重复题及编号冲突
node --import tsx scripts/import-question-bank-500.ts --check
# 在已配置的正式库中一次性导入并发布
node --import tsx scripts/import-question-bank-500.ts --apply
```

数据库连接沿用项目所有者的本机服务端配置，采用官方CA验证TLS。导入使用事务和短暂表锁，写入后逐条读取比对，再提交。失败时回滚。已有题目不被覆盖；相同批次重复运行不会重复插入；若已导入的关卡在后台被修改，则停止而不覆盖修改。写入检查报告在 `import-reports/`，不含账号密码或连接信息。

自动检查包括500道题的唯一性、与原45道题的去重、选项与答案结构、答案位置均衡，以及170道可直接用算式验证的数学题。其余内容按文字和情境核对；题库可在管理后台继续编辑。测试通过不等同于教研机构审定。

新关卡写入现有数据库即生效，不需要重新部署网站。未配置数据库时，前台离线示例仍使用原9关、45道题。
