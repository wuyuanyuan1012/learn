# 北师大版小学数学题库（第一批）

本批已按用户授权整理 1—6 年级上下册，覆盖 12 册教材的 86 个核心单元。每个核心单元至少 10 题；全库 199 关、1,990 题，均为可自动判分的四选一题，包含提示和解析。

分类沿用：数的认识、计算、应用题、图形与几何、单位与测量、统计与可能性、规律与逻辑。每关保存北师大版、年级上下册和知识点标签。前台「全部练习」选年级和数学，再按分类筛选；搜索例如 `3年级下册` 可限定册别。

## 内容性质与边界

- **1,047 题**：提取教材中的可独立计算算式，重新制作选项、提示、解析；不是逐字转录整道教材练习。
- **900 题**：按教材单元知识点改编补充，覆盖分数、几何、统计、方向位置、时间及各类运算应用。
- **43 题**：将已核对算式改为逆向填空，用于补齐每关 10 题。
- 改编题的来源页是该知识单元的参考起始页，**不表示题目原文出现在该页**。提取算式记录实际 PDF 页、印刷页、原 OCR 和交叉识别结果。
- 本批完成的是全册核心单元覆盖，**不代表已导入全部教材原题**。「整理与复习」「总复习」「数学好玩」不作为新增知识单元统计；其中可读算式可能被收录。
- 竖排分数、看图、拼摆、作图、开放题不能仅凭文字识别直接发布。`pending-arithmetic.json` 保存 1,119 个未采用候选；`pending-visual-pages.json` 是按操作关键词检出的页面辅助索引，不是全部未导入原题的逐题清单。高年级分数等知识以改编题覆盖。

## 来源和核对

来源：[ChinaTextbook 北师大版目录](https://github.com/TapXWorld/ChinaTextbook/tree/5a80345f2043ba6f8db8d7be9cf3db82725ff1f7/小学/数学/北师大版)。固定 commit 为 `5a80345f2043ba6f8db8d7be9cf3db82725ff1f7`。

`sources.json` 记录 15 个源文件的不可变下载地址、SHA-256、合并后 12 本教材的页数和单元目录。二上、四上、六下的分片按 `.1`、`.2` 顺序拼接。全部 1,364 页均完成中文和数学两路 OCR；24 页目录经过图像核对，印刷页码为 PDF 页码减 4。

计算候选经 Vision OCR 与裁剪图 Tesseract 的结果比对后筛选；一致并不意味着完全可靠，因此另外查看了跨 12 册的算式样本（详见 `review.json`）。5 下和 6 上的候选容易是完整题目的局部片段，本批全部转待核对。重复算式全批去重，其他出现位置记录在来源 aliases 中。

`manifest.json` 逐题记录确定性 UUID、来源、内容类型和计算证明；`coverage.json` 逐单元统计覆盖。答案校验使用独立 BigInt 有理数解析器，检查精确小数、分数、逆向等式、余数以及干扰项不能等于正确答案。

## 复现与导入

```sh
# OCR 需要 macOS Vision；PDF、逐页 OCR 和图像暂存于 /tmp/learn-bnu。
# sources.json 是源文件的永久索引，临时图像不是题库运行依赖。
python3 scripts/bnu-math/extract-arithmetic.py
# 使用保存的算式交叉核对结果构建发布题目
python3 scripts/bnu-math/build-bank.py
node --import tsx --test tests/bnu-math.test.ts
npm run typecheck
node --import tsx scripts/import-bnu-math.ts --check
node --import tsx scripts/import-bnu-math.ts --apply
node --import tsx scripts/import-bnu-math.ts --check
```

导入器按 15 关分批写入同一数据库事务，对原有行校验指纹，已有本批 ID 内容不同则拒绝覆盖。导入结果见 `../import-reports/bnu-primary-math-v1-applied.json`，事后检查见同目录 `-check.json`。这是数据导入，无需部署前后台代码。以前清空的数学题库没有恢复。

手机验证脚本 `scripts/verify-bnu-math.ts` 使用临时会员和已有生产构建，检查全部年级、12 个册别、各分类，以及两关完整答题；测试会员在 finally 中删除。结果记录在导入报告目录。
